AsserTcl: Assertions for the Tcl Language

A Brief Overview

AsserTcl provides powerful assertion commands to enable a Tcl developer to write robust, self-checking programs. This package provides assertion commands for:

  • Point assertions, a la the assert() macro in C,
  • Procedure input assumptions, * Procedure output and return value assurances, and
  • Variable lifetime assertions (a fancy interface to 'trace')

By default, assertions generate an error exception that aborts the script, but this can be overridden by providing a failure- action for the assertion, allowing the program to simply print some debugging information, or even to recover from the failed assertion, and to continue the program. Additionally, for the list and array aggregate data structures, quantifier commands are added, for testing whether an expression holds universally or existentially over a data structure.

For example, the point assertion

assert {[lall {i1 i2} $list {$i1 <= $i2}]} {puts "list is not sorted!"}

checks that $list is sorted (using the universal list quantifier 'lall' over two-item sequences), and prints a message if it is not, rather than aborting the script. The quantifier invocation is read as "for all two item sequences in $list, the first item is less than or equal than the second item".

For concerns about deployment efficiency, assertions can be disabled through an extensive control interface -- the "asssertcl" command. This interface lets you disable assertions globally, or locally by procedure or by variable (for always assertions). A 'null' package is also available for deployment of a program. n the future, we hope to provide automatic commenting-out of assertions as a complete disabling mechanism.

NOTE: The tar file does *not* contain a top-level directory. Be sure to make a directory before untarring the distribution.

Version and Retrieval Information

This release of AsserTcl is 1.0, the first mainstream-ready version. The most notable changes from 0.91 are:

  • An extensive control interface for enabling/disabling assertion checking.

AsserTcl has been developed on Tcl 7.6, but has been run on Tcl 8.0a2, though not extensively tested. It has not been tested with [incr Tcl] or any other add-on, but I don't imagine that it would be incompatible.

AsserTcl is a Tcl-only package. You can get AsserTcl at http://www.cs.colorado.edu/~jcook/TclTk

I would love to hear about any suggestions, problems, and requests that anyone would have. I intend to support and continue development on AsserTcl, so I will seriously entertain any requests you have.
